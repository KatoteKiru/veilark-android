## Русский

Обновлённый Android-клиент Veilark с TrustTunnel и sing-box.

- TrustTunnel обновлён до стабильной версии 1.1.7. Сохранены разделение по
  приложениям и доработки жизненного цикла туннеля.
- По сравнению с прежним публичным rc20 интерфейс перешёл на Material 3
  Expressive; улучшены навигация, диалоги и поддержка системного Back.
- Обновление GEO проверяет размер и SHA-256 файлов; при недоступности сети
  приложение может использовать сохранённые и встроенные наборы правил.

Это открытая сборка без встроенных подписок: добавьте собственную ссылку или QR.
Для установки скачайте файл **Veilark-Android-0.8.0-rc41-oss.apk**.

Подпись OSS сохранена: APK обновляет прежний **app.veilark.android** поверх.
Он не заменяет OTA-приложение **uk.senyasenyavski.veilark** — у этих сборок разные
package и ключи. В этой OSS-сборке обновления устанавливаются из GitHub вручную.

Сборка, unit-тесты, lint и проверка подписи выполняются в GitHub Actions.
Они не заменяют проверку VPN на физическом устройстве или замеры батареи.

## English

An updated Veilark Android client with TrustTunnel and sing-box.

- Updated TrustTunnel to stable 1.1.7, retaining per-app routing and tunnel
  lifecycle hardening.
- Compared with the previous public rc20, the interface now uses Material 3
  Expressive, with improved navigation, dialogs and system Back handling.
- GEO updates verify file sizes and SHA-256 hashes. Saved and bundled rule sets
  remain available when downloads cannot complete.

This open-source build contains no bundled subscriptions. Import your own URL
or QR code. Download **Veilark-Android-0.8.0-rc41-oss.apk** to install.

The existing OSS signing key is retained for **app.veilark.android** upgrades.
This APK does not replace the separate **uk.senyasenyavski.veilark** OTA app:
their package IDs and keys differ. OSS updates are installed manually from GitHub.

GitHub Actions checks the build, unit tests, lint and signing identity. These
checks do not constitute physical-device VPN acceptance or battery measurements.
