# 0.8.0-rc33

Единый монохромный логотип Veilark вместо щита. Спокойные светлая и тёмная
темы, плавная смена состояния подключения без лишних анимаций размеров.
Кнопка подключения корректно растёт при увеличении системного шрифта.
VPN-ядра, подписки и настройки маршрутизации не изменены.

Release evidence must distinguish JVM/build verification, emulator UI inspection,
and physical device/network acceptance. A successful build is not the last one.
