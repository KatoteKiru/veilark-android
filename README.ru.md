# Veilark для Android

[English](README.md) | [Русский](README.ru.md)

Veilark — независимый Android-клиент для пользовательских VPN-профилей. В
приложении есть два сетевых движка: `sing-box` для совместимых прокси-протоколов
и `TrustTunnel` для ссылок `tt://`. Репозиторий содержит приложение, адаптеры,
тесты и инструкции воспроизводимой сборки. Серверная часть, VPN-доступ, аккаунты
и подписки в проект не входят.

## Возможности

- Android 10+ (`minSdk 29`), `arm64-v8a` и `armeabi-v7a`;
- русский и английский интерфейс по языку Android или настройке языка приложения;
- независимые режимы sing-box 1.13.19 и TrustTunnel 1.1.4;
- несколько подписок и профилей с обновлением, переключением и удалением;
- импорт из ссылки, буфера обмена, файла и QR-кода;
- ссылки VLESS, Trojan, Hysteria 2, VMess, Shadowsocks, TUIC и AnyTLS;
- совместимое подмножество JSON sing-box/Xray и YAML Clash/Mihomo;
- ссылки TrustTunnel `tt://` и списки таких ссылок;
- раздельное туннелирование по приложениям для обоих движков;
- ручные правила доменов и CIDR для sing-box;
- плитка быстрых настроек, технический журнал и ручная проверка задержки;
- зашифрованное хранение профилей через Android Keystore.

Импорт намеренно ограничен форматами, которые Veilark может проверить и
безопасно преобразовать. Произвольный граф sing-box, все плагины Shadowsocks и
каждый диалект сторонних панелей не заявлены как совместимые.

## Публичная и частная сборки

| Вариант | Application ID | Встроенные профили | Самообновление |
|---|---|---:|---:|
| `oss` | `app.veilark.android` | нет | нет |
| `private` | задаётся локально | только локальные файлы | подписанный частный канал |

Обе сборки используют один код приложения. Приватные адреса, подписки и ключи
хранятся только в игнорируемом `private.properties`. Публичная сборка также
удаляет разрешение установки APK и update `FileProvider` из итогового манифеста.

## Сборка OSS

Требуются JDK 17 и Android SDK API 36.

```bash
./gradlew testOssDebugUnitTest lintOssRelease assembleOssDebug
```

Устанавливаемый debug APK появится в
`app/build/outputs/apk/oss/debug/app-oss-debug.apk`. Для подписанного release APK
задайте четыре переменные окружения:

```text
VEILARK_OSS_KEYSTORE
VEILARK_OSS_STORE_PASSWORD
VEILARK_OSS_KEY_ALIAS
VEILARK_OSS_KEY_PASSWORD
```

Затем выполните `./gradlew assembleOssRelease`. Закрытый ключ нельзя добавлять в
репозиторий. Полный порядок релиза описан в
[`docs/RELEASING.md`](docs/RELEASING.md).
Проверки политики и локализации Google Play вынесены в
[`docs/GOOGLE_PLAY_RELEASE_CHECKLIST.md`](docs/GOOGLE_PLAY_RELEASE_CHECKLIST.md).

## Проверка импортов

JVM-тесты покрывают отдельные URI, base64-списки, JSON sing-box/Xray,
Clash/Mihomo YAML и смешанные списки с `tt://`. Instrumentation-тест использует
публичный localhost fixture из TrustTunnelClient и вызывает настоящее native
ядро. Для его запуска требуется ARM-устройство:

```bash
./gradlew assembleOssDebugAndroidTest
./gradlew connectedOssDebugAndroidTest
```

Обычный x86_64 Android Emulator не подходит: встроенные нативные библиотеки
сейчас содержат только ARM ABI.

## Безопасность и приватность

OSS-вариант не содержит VPN-аккаунтов, аналитики, рекламных SDK, приватных
подписок и частного канала обновлений. Приложение обращается к адресам,
импортированным пользователем, и к проверкам, которые пользователь запускает
сам. Технический журнал скрывает чувствительные значения. QR-сканер использует
Google ML Kit на устройстве; SDK может передавать метрики производительности и
использования, как указано в двуязычном файле
[`PRIVACY.ru.md`](PRIVACY.ru.md).

Veilark — клиент, а не гарантия анонимности. Результат зависит от
импортированного сервера и его оператора. Уязвимости следует сообщать по
закрытой процедуре из [`SECURITY.md`](SECURITY.md), а не через публичную задачу.

## Лицензии и упоминания

Veilark распространяется на условиях GPL-3.0-or-later. В APK включены sing-box
на условиях GPL-3.0-or-later и изменённый Android-адаптер TrustTunnelClient на
условиях Apache-2.0. Точные версии, исходные коммиты, патчи, сборочные данные и
хеши находятся в `vendor/` и
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md). Полные тексты лицензий и
уведомления также доступны внутри приложения в разделе **О Veilark**.

Veilark — независимый проект сообщества. Он не связан с AdGuard, TrustTunnel,
SagerNet или sing-box и не одобрен ими.
