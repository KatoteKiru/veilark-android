# macOS OTA audit — 2026-08-31

This audit covers the published Veilark macOS preview chain and the unshipped
`1.0.6` candidate. No server or release was changed during the audit.

- The live DMG is 133,619,252 bytes. Its SHA-256 is

- The DMG metadata says `signed=false`; its manifest notes that Apple signing and

There was no automatic channel check in the application lifecycle: `check()`
was reachable only from the Settings button. In addition, the source candidate
still identified itself as the already-published `1.0.5 / 10005`, so publishing
the same metadata could never make an update visible to installed 1.0.5 clients.

The source candidate is now `1.0.6 / 10006` and performs one advisory background
check at startup. Download and installation still require explicit user action.
Publishing a new signed manifest remains a separate release operation.

## Verification chain

1. The JVM client fetches only an HTTPS manifest with bounded size and redirects.
2. It validates schema, platform, semantic version, monotonically increasing
   build, architecture, DMG URL, SHA-256, and Ed25519 signature.
3. It downloads to a temporary file with a 750 MiB limit, verifies SHA-256 and
   disk-image integrity, then atomically promotes the cached DMG.
4. The native updater independently verifies the manifest signature and DMG
   hash, validates bundle identity/version/build, waits for the old process,
   stages replacement on the same volume, rolls back on failure, and relaunches.
5. When production Gatekeeper mode is enabled, both the JVM and native updater
   must enforce it. The build now compiles the native updater with the same flag.

## Remaining Apple gates

The following cannot be satisfied by the current unsigned preview channel:

- Developer ID signing of nested engines, helper/updater, application, and DMG;
- hardened runtime and the required entitlements;
- Apple notarization and stapling;
- `codesign --verify`, `spctl --assess`, and `stapler validate` on a physical Mac;
- a real installed-version upgrade preserving encrypted profiles and routing.

`macosOtaRequireGatekeeper` must remain `false` until these gates are complete.
